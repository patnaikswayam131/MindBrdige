# MindBridge Visual Assets

These assets were generated for the MindBridge landing page and student dashboard redesign.

## Recommended placement

- `landing-light.webp` — landing page illustration for the light theme.
- `landing-dark.webp` — landing page illustration for the dark theme.
- `dashboard-light.webp` — student dashboard ambient illustration for the light theme.
- `dashboard-dark.webp` — student dashboard ambient illustration for the dark theme.

PNG versions are included when lossless source files are preferred.

## Suggested CSS

Use the images as `img` elements or as non-essential decorative media. Prefer `object-fit: cover` with `object-position: center` and a responsive aspect ratio rather than stretching.

Suggested landing image ratio: ~4:3.
Suggested dashboard image ratio: ~3:2.

Do not bake interface text, buttons, navigation, or controls into these images. Keep all functional content in HTML/CSS so it remains responsive and accessible.
