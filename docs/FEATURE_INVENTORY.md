# MindBridge — Baseline Feature Inventory & Feature Preservation Checklist

**Project Name:** MindBridge — Student Mental Health & Emotional Well-Being Platform  
**Document Version:** 1.0.0  
**Audit Date:** 2026-10-02  
**Audit Scope:** Full codebase (Frontend pages, Backend services, Database, Shared scripts, CSS system, APIs)

---

## 1. Feature Preservation Gate Principles
1. **Zero Silent Removals:** Every feature identified in this inventory must either be preserved in its existing route or enhanced in its planned destination.
2. **Data & Storage Integrity:** No user databases or `localStorage` structures (`mb_daily_checkin`, `mb_appointments`, `currentUser`, `mindbridge_thread_id`, `users`) may be deleted or broken.
3. **Behavioral Parity:** An improved visual interface is never an acceptable substitute for working interactivity, form submission, scoring, or API communication.
4. **Regression Verification:** At the end of every major phase, each feature in this checklist must be tested and marked as `VERIFIED`.
